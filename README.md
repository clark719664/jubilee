# Jubilee

A holiday tracker for kids. Count the sleeps until the next holiday, watch it come alive, then play, cook, craft and learn something new for 52 celebrations from around the world.

**Play it: https://clark719664.github.io/jubilee/**

- Free, with no ads, accounts, tracking or analytics
- Everything stays on your device and works offline once loaded
- Countdowns, games, stories, colouring pages, recipes and crafts for every holiday

## Run it locally

```bash
npm install
npm run dev
```

`npm test` runs the test suite, `npm run lint` checks the code and `npm run build` makes the site in `dist/`. Pushing to `main` tests and publishes it to GitHub Pages.
